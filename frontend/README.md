# React 前端（保留原样式）

默认 `/` 及原页面深链接由 React 渲染，`/app/` 为兼容别名。迁移完整保留原双栏、HTML 层级、class、字体、配色、尺寸、Canvas、移动端规则和动效，不包含界面改版。

## 已迁移范围

- 外壳、账号弹窗与原登录页：登录/注册、找回/重置、改密、改邮箱，使用 HttpOnly Cookie。
- 聊天：消息、流式回答、工具卡片、附件输入、快捷回复、历史搜索、取消及断线恢复。
- 实验列表与分类：搜索、状态/归档/标签/日期筛选、行/卡片、日期组、置顶、分类维护与最多四条对比，手机菜单与浮层由 React Portal 管理。
- 实验详情：完整字段、富文本/表格编辑、草稿、保存/取消、版本冲突、归档/恢复、附件和实验子对话。
- 分析列表/详情：删除、引用实验、证据快照过期提示、Markdown、打印和独立分析子对话。
- 时间线、模板库、实验对比、模型与本机设置、主题及声音偏好。
- 打印预览、图片/PDF/文本/CSV/Excel 附件预览；Excel 工作表、分页、样式、合并单元格、缩放及表格选择复制。桌面保存通过已授权内容桥接本机文件对话框。

原外壳 CSS 和 vendor marked/Quill 继续直接加载，顺序保持一致。页面 CSS 从原模板逐字提取并共用。Canvas、分栏、转场、主题和声音为生命周期受控的 ES 模块；React 入口不再加载旧业务脚本、获取 HTML 片段或执行模板内联脚本。工具卡片正文仍保留原 HTML 构建函数，打印文档继续使用服务端模板；它们不是旧页面加载器。

旧 Shell、片段路由、15 个旧页面/基础模板和重复脚本已删除，`/ai-shell/` 重定向到 React 首页。测试目录只保留无脚本的原外壳 DOM/CSS 基准。生产模板仅保留实验打印、报告打印，以及独立 e2ee 演示仍使用的模板；原 CSS、字体与音频继续服务当前 React 前端。回退发布需要一起恢复前端、API 和代码版本。

旧表单接口不再渲染已删除的页面：`POST /settings` 返回与新设置接口一致的 JSON；`POST /api/parse` 返回解析结果 JSON，持久化仍使用 `/api/parse/confirm`。旧片段和已删除脚本返回 404。

## 开发与部署

需要 Node.js 22.12+ 和现有 Python 依赖。首次构建：

```powershell
cd frontend
npm ci
npm run build
cd ..
python app.py --headless
```

访问 `http://127.0.0.1:5000/`。缺少 `frontend/dist/index.html` 时返回 503 及构建提示，避免静默使用旧页面。

开发时先启动后端，再在 `frontend/` 运行 `npm run dev`，访问 `http://127.0.0.1:5173/app/`。Vite 将 API、原静态资源和打印输出代理到 `http://127.0.0.1:5000`；改变后端端口须同步修改 `vite.config.ts`。

部署应携带 `frontend/dist/`、`static/`、`ai-shell/` 和 `templates/`。Node 只用于构建，生产页面由 Flask 提供；无需另起 Node 服务。构建资源统一为 `/app/assets/`，根路径与 `/app/` 共用。dist 与 node_modules 不提交到 Git，发布流程必须显式构建和复制 dist；现有打包流程也需包含该目录。

## 数据和会话兼容

React 页面复用原实验、分类、分析、附件与 Agent 服务。新增 `/api/v1/` 提供页面 JSON；完整记录保存携带初始 revision，409 保留草稿，不能自动覆盖新版本。附件操作后先刷新完整记录，失败时锁住编辑，避免旧快照覆盖附件引用。

有效账号使用账号作用域。为保留现有功能，无凭据时仅在应用明确装配独立离线库的情况下允许离线工作区；失效凭据返回 401 并清理 Cookie，不能在同一请求中静默切换到离线库。设置接口只返回字段白名单和掩码，不返回 API 密钥，留空表示保留原密钥。

本次完成的是 React 前端迁移。服务端任务持久化/后台化、统一事务、账号数据迁移、集中部署及退役本机离线/同步仍属于后续架构工作，见 `docs/server-react-refactoring-plan.md`。

## 验证

```powershell
cd frontend
npm test
npm run build
cd ..
python -m pytest tests/test_react_frontend.py
```

前端测试覆盖原 DOM/样式与资源顺序、账号、流式去重、列表筛选/分类/置顶/对比、详情编辑/409、附件失败、子对话、设置、报告、预览及外壳导航/卸载。后端使用内存 SQLite 验证 Cookie、账号隔离、显式离线作用域、分页、设置脱敏、证据快照、附件与版本契约、默认入口和深链接。

浏览器验收使用隔离数据，不读写真实实验库或调用付费模型。桌面/手机关键节点与原版进行位置、尺寸、字体和边框对照；另验证编辑保存、搜索/对比、报告/打印及 CSV 预览。真实模型、原生系统保存/打印对话框未作端到端验收。
