# 前端维护性整理（2026-10-17）

本轮在保持已有页面结构、样式和接口协议的前提下，处理 React 迁移留下的资源加载、模块连接和职责混杂问题。

## 当前代码边界

```text
frontend/src/
  app/                 应用装配、页面挂载、通用页面数据 Hook
  layouts/             外壳结构和公共弹窗
  features/            账号、聊天、实验、分析、预览、设置
  shared/
    api.ts             公共 JSON 请求、401 和修订冲突错误
    markdown.ts        统一 Markdown 解析
  styles/              原 CSS 的唯一源码位置
  runtime/
    services.ts        跨模块服务的类型契约
    start.ts           外壳初始化与清理
    panel.js           导航与页面状态
    canvas-engine.js   独立原生绘图、命中与动画
    canvas-data.js     Canvas 统计数据接口适配
    split-layout.js    分栏拖动、尺寸恢复、横竖屏切换
    motion.js          转场
    theme.js           主题持久化和系统主题监听
    sound.js           音频播放、曲库和声音偏好
    scope.js           事件、请求、定时器和动画帧清理
```

## 本轮变化

1. 将 `static/css/`、`ai-shell/static/css/` 的样式移入 `frontend/src/styles/`。公共样式保持原加载顺序，页面样式随组件提供；构建生成带内容哈希的公共 CSS，页面不再依赖单独请求旧 CSS 地址。清除 CSS 中失效的 Jinja 标记。
2. 以 npm 锁定原来使用的 Marked 15.0.12，聊天、工具卡片和详情共用同一解析函数。删除入口的第三方全局脚本，以及无业务引用的 Quill 文件。
3. 将实验目录中的通用请求移至 `shared/api.ts`，更新全部使用方。流式请求、二进制预览和会话校验具有不同响应约定，保留各自处理，不增加通用协议框架。
4. 删除 `legacy/invoke.ts`。原先 `invoke('PanelManager.navigate', ...)` 等字符串调用改为显式导入 `services` 后调用方法，组件、运行时和测试均不再注册应用级 `window` 属性。浏览器自身的 `window.history`、事件和尺寸接口继续正常使用。
5. 从 `panel.js` 拆出分栏模块，通过少量回调连接 Canvas 重绘和导航标题刷新。保留原有尺寸存储键、移动断点和滚动位置保护；卸载中断拖动时恢复鼠标和文本选择状态。
6. 删除声音、主题模块中旧设置页的 DOM 写入及事件委托，以及无调用方的旧比较/筛选接口。React 独立管理设置页控件。
7. 工具卡片和选择器已成为 `ToolCard.tsx`、`SelectorCard.tsx` React 组件，删除 `tool-cards.js` 字符串生成器。勾选、搜索、失败重试和弹窗状态由 React 管理，普通字段自动按文本渲染，保留原有 class 和外观。
8. Canvas 算法从导航模块中独立，由 `CanvasSurface.tsx` 的 Effect 创建并清理；引擎接收节点、模式和导航回调，不读取应用服务或请求接口。隐藏时暂停帧循环，恢复时只启动一次；统计请求由单独的适配层提供。`panel.js` 从本轮开始的 1,352 行减至约 605 行。

## 仍然保留的部分及理由

- 图片和内置音频现已移入 `frontend/public/`，随 Vite 构建复制到 dist；旧 URL 重定向到 `/app/img/`、`/app/audio/`。用户上传音乐继续使用服务端账号附件接口。
- 打印模板、原版 CSS、脚本集中于 `frontend/src/features/print/`。模板仍由服务端填充，打印逻辑通过独立 Vite 入口构建并共用 npm Marked；重复静态 Marked 和无引用的 HTMX 已删除，Marked 许可证移入 `frontend/licenses/`。
- Canvas、声音和分栏使用原生浏览器 API；不把绘图每帧状态转换为 React 状态。
- Canvas 仍使用原生绘图 API 和 JavaScript 算法，React 管理生命周期；不把逐帧动画状态放进 React。工具卡片已完成组件化，不再保留 HTML 模板拼接。

`services` 是单个前端外壳的模块内注册表，保留了部分运行时耦合；它替代浏览器全局和字符串解析，没有引入依赖注入框架。后续增加业务功能应优先使用功能内 Context、普通函数和明确参数，不继续扩充跨功能共享状态。
