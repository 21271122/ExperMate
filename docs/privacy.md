# 数据与隐私说明

> 更新日期：2026-08-28
>
> 本说明描述当前开源版 ExperMate｜小同门的默认行为，不构成法律意见。部署者自行修改代码、配置模型服务商或运行同步中继后，应按实际行为更新本说明。

## 一、默认数据位置

ExperMate 是本地优先应用。实验记录、聊天记录、分析报告、分类、附件、音乐库、账号安全材料和本机设置默认保存在当前设备，而不是由 ExperMate 官方服务器集中保存。

源码运行时，主要数据位于项目目录的 `data/`；未来桌面安装版将使用当前 Windows 用户的应用数据目录。数据包括：

- `data/data.db`：登录账号的数据；
- `data/offline.db`：未登录时的本地数据；
- 附件二进制内容：保存于对应 SQLite 数据库；
- `data/_e2ee_accounts.db`、`data/_e2ee_kms.key`：账号恢复、登录和同步相关的本机安全材料；
- `config.yaml`、`.env`：模型服务商、网络和其他运行配置，可能包含 API Key。

请不要将这些文件提交到 GitHub、发送给陌生人，或上传到公开网盘。完整备份与恢复方法见[数据、备份与恢复](operations/data-and-backup.md)。

## 二、何时会向外发送数据

### 1. 模型服务商

当你发送消息、要求 Agent 读取附件、生成实验记录或生成分析报告时，应用会将完成该请求所需的上下文发送给你在设置中自行配置的模型服务商。

发送内容可能包括：

- 当前对话及其必要的上下文摘要；
- Agent 为回答问题而读取的实验字段、更新记录、分析报告或聊天历史；
- 你上传并要求 Agent 阅读的附件内容；
- 图片附件本身（仅当所选模型支持视觉且该图片被用于当前请求）。

不同模型服务商的数据保留、训练和安全政策不同。请在填写 API Key 前阅读该服务商的隐私政策，并避免将不应交给第三方处理的原始数据发给 Agent。

### 2. 可选同步中继

多设备同步默认不是必需功能。启用后，客户端会向你配置的同步中继发送同步数据包。当前设计会在客户端加密实验、分析、分类、附件等同步内容；中继用于转发和暂存，不能按正常流程直接读取这些内容。

中继仍会处理为同步所必需的网络连接和有限标识信息，例如请求时间、账号/设备关联信息及加密数据包。中继地址、部署者和访问控制均由使用者决定；自建中继时请使用 HTTPS、强 API Key 和独立备份。

### 3. 页面前端依赖

Quill、HTMX 和 Marked 等页面依赖随仓库在 `static/vendor/` 中本地提供。打开桌面窗口或网页页面时，应用不会为了加载这些库而请求第三方 CDN。

## 三、不会默认发生的事

- ExperMate 不提供默认的官方云端数据仓库；
- 不会在未配置模型服务商时自动把实验或聊天上传给模型；
- 不会把本机数据库、附件或 API Key 自动提交到代码仓库；
- 不会把离线数据自动并入登录账号；
- 不会因为安装或升级而主动删除你的数据目录。

## 四、你的控制方式

- 可以不登录，以离线数据库使用应用；
- 可以不启用同步；
- 可以在设置中更换或清除模型 API Key；
- 可以删除附件关联、归档实验，或按数据文档备份、恢复和清理本机数据；
- 可以关闭应用后备份整个 `data/` 目录和配置文件；
- 可以在部署配置中限制监听地址为 `127.0.0.1`，避免局域网或公网访问。

## 五、安全提示

API Key、账号恢复材料和本机数据库应视为敏感信息。共享电脑、公开服务器或局域网部署前，请设置操作系统账户权限，并阅读[服务器与同步中继部署](operations/deployment.md)。

若发现会导致数据泄露、未授权访问或密钥暴露的安全问题，请不要在公开讨论中贴出真实密钥、数据库或附件。项目公开发布前会在仓库补充专门的安全反馈联系方式。
