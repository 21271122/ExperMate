# 数据与隐私说明

更新：2026-10-16。本文说明当前服务端运行模式。

## 数据保存位置

实验、分析、附件、音乐、收藏与主/子会话保存在部署者管理的服务端 SQLite 数据库中，按登录账号隔离。账号认证、恢复密钥、模型配置、自定义模板和运行日志同样位于服务端数据目录。浏览器只保存主题、音量、列表视图、窗口标识与账号显示名等偏好，并通过 HttpOnly Cookie 访问服务端会话。

服务端可以读取业务数据和附件。当前模式不提供针对服务端的端到端加密；历史 `e2ee` 模块名用于账号安全与恢复组件，不代表浏览器持有业务解密密钥。可选 SQLCipher 属于服务端静态存储加密，不能阻止拥有运行密钥的服务端读取。

## 模型与邮件服务

模型调用由服务端发起，可能发送请求所需的对话、实验字段、分析、更新记录、附件内容与图片像素。服务商和模型由部署管理员配置；普通账号不能读取或修改全局模型密钥。服务商的数据处理政策由其自身决定。

配置 SMTP 后，找回密码和更换恢复邮箱会将恢复凭证发送到相应邮箱。接口不向浏览器回显恢复 token；没有 SMTP 时恢复功能明确不可用。

页面依赖随仓库提供，不为加载界面请求第三方 CDN。当前主应用不启用历史同步中继或 Windows 凭据库。

## 登录、迁移与备份

业务访问必须登录。会话失效后要求重新登录，不切换到匿名离线数据。旧离线库只通过运维手动指定账号导入，不自动归入任意账号；本轮尚未执行真实旧库导入。

服务端配置、账号库、密钥、业务库、日志及备份均可能含敏感信息，应由部署者限制文件访问并成套备份。日志可能包含对话和工具操作内容。具体目录与恢复步骤见[数据与备份](operations/data-and-backup.md)。
