| 操作 | 结果 |
| --- | --- |
| 未登录进入 | 显示原登录弹窗；不加载离线业务数据 |

| 打开实验详情 | 原字段、折叠面板、编辑/打印/归档入口和附件区域正常 |
| 文本附件预览 | 显示服务端保存的测试附件正文 |
| 附件状态 | 显示“已保存到服务端”，移除“待同步”旧提示 |
| 普通用户设置 | 模型表单只读、保存按钮禁用，外观和声音偏好保留 |
