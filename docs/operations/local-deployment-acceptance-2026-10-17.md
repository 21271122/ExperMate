# Windows 本地部署与浏览器验收

验收时间：2026-10-16 晚至 2026-10-17 凌晨。

部署入口：`http://localhost:8765`。使用项目 `.venv` 的 Waitress 3.0.2，单进程 16 线程，监听 `127.0.0.1`；React 页面由同一服务提供。启动和停止操作见[部署说明](../../deploy/local-windows/README.md)。

## 数据与模型

- 使用独立的 `data/local-server/`；未导入旧库、旧附件或旧会话。
- 复制本机已有模型配置，实际调用已配置的服务商，无模拟响应。测试内容仅为生成的验收数据。
- 创建 `local-admin` 与 `local-reader` 两个账号，随机密码仅保存于被 Git 忽略的 `data/local-server/access.json`；关闭公开注册。
- 本次保留测试记录与附件，方便继续检查。
